# Phase Gate Protocol

Antigravity must stop after each phase and present:
1. What was implemented.
2. Files created or changed.
3. Commands run, exactly as executed.
4. Verification results (`PASS`, `FAIL`, `NOT RUN`).
5. Issues or owner inputs still required.
6. The path to the phase report.

Proceed only after explicit approval. Never mark a phase complete solely because files were generated. A phase is complete only when its acceptance checks have been run and the results recorded honestly.
