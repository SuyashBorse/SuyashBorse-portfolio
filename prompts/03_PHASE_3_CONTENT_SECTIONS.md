# Phase 3 — Hero, About, Skills, and Projects

Complete Phase 3 only after Phase 2 has been approved.

## Tasks
1. Compose the home page from modular sections in `index.astro`.
2. Implement Hero with the exact headline, animated sub-headline, and exact CTA labels from the specification.
3. Implement About Me using only the supplied student, CodeChef, LeetCode, and DSA facts.
4. Implement the Skills bento grid with every skill in all four specified categories.
5. Implement data-driven project cards for EcoPilot AI, KanFlow, and SIH 2026 Submissions.
6. Add accessible Lucide icons, stack pills, and GitHub/Live Demo affordances.
7. Keep project URLs and stack entries unconfigured until the owner supplies them. Do not use fake `href="#"` anchors. A disabled state or non-link placeholder must make the missing configuration clear.
8. Keep all exact copy and project descriptions faithful to `PROJECT_SPECIFICATION.md`.
9. Add hover/focus interaction and motion only where useful. If Framer Motion is used, it must remain inside React islands.
10. Ensure each section works without JavaScript where practical; animated text must degrade gracefully.

## Verification gate
Check required content against the spec, check keyboard behavior, test responsive layout, and run the production build. Create `reports/PHASE_3_REPORT.md` with a content audit table mapping each requirement to its implementation file.

Stop for approval.
